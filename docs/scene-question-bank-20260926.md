# 生活场景原创题库内容审阅

版本：3.0-scenes-20260926

六套各24题、6个内容组，共144题。每套包含3组困扰和3组现实支持或应对；组是内容组织方式，不是经过验证的心理学分量表。所有题目为本产品独立编写，没有翻译、改写或移植外部量表。

## 审阅原则与现阶段证据

按题意相关性、覆盖范围和可理解性逐项整理观察目的；固定观察期；使用具体生活行为；允许不适用或不愿回答；避免反向题混淆、诊断阈值与总体健康分数。内容审阅由开发阶段完成，尚没有独立临床专家审阅、目标用户认知访谈、样本信效度或常模研究。因此不得宣传为专业认证、临床筛查或已验证的人格分类。

方法参考：[COSMIN](https://www.cosmin.nl/) 与 [CDC cognitive interviewing](https://www.cdc.gov/nchs/ccqder/question-evaluation/cognitive-interviewing.html)，仅用于问卷评价方法，不是题目来源或机构背书。

## 回答与整理规则

从不、很少、有时、经常、几乎总是分别储存为0到4，仅用于频率分类。跳过不计为0。内容组至少答3题且覆盖75%才概括；模块答题覆盖至少75%，候选组至少2题且半数以上选经常或几乎总是才匹配类型。只比较候选组的较常回答比例，不能解释为置信度或严重程度。两个最高比例相差小于15个百分点可组成双特点；三个及以上接近时保留多面描述，不强选主类型。

每套6种单特点和15种双特点，共126个预设描述，代码为2字母加2数字。不跨模块合并，不给支持与困难相互加减。所有结果保留六个侧面、原题和用户回答。数字是标识，不是排名。类型规则版本 types-20260926。

## 适用条件与边界

成人自我观察。多数模块回看过去两周；变化适应回看过去一个月，近期未发生生活变化可直接选择其他模块。不要求回忆创伤细节；关系表达建议只适用于安全的关系。值班、照护、经济与资源条件均可能影响答案，低资源频率不解释为个人不足。安全支持独立分流，不计分、不推断危险等级。

## 后续研究计划（尚未完成）

邀请目标用户逐题复述、说明回忆与选项选择过程；覆盖轮班、照护、待业及不同网络使用需求等处境。再邀请具备相关资质的独立专业人员审阅。内容迭代冻结后，另行设计样本研究，评估缺失、理解偏差、维度结构、重复回答一致性和公平性。任何阈值调整必须有版本与依据，不能把现有软件测试当作心理测量验证。

## 工作与休息边界 (WK)

观察期：过去两周。请按观察期内实际发生的情况回答。没有遇到相应情境，请选“不适用 / 不愿回答”，不用猜自己会怎样。题目不要求描述事件细节。

### 工作还留在脑子里

性质：困扰或负担。看离开工作后，任务是否仍占着注意力。

行动：离开工作前记下下一步从哪里继续，让休息时不必一直记着。

解释边界：未完成任务也可能源于工作量与制度安排，不能只归因于个人。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| wk_mind_1 | 离开工作场所或关闭工作页面后，我仍在脑中排演未完成的任务。 | 离岗后的任务思考 |
| wk_mind_2 | 正在做自己的事时，我又把注意力转回可能出错的工作细节。 | 工作思绪的生活侵入 |
| wk_mind_3 | 本来准备休息，我却重新打开已经结束的工作内容查看。 | 休息后的重复检查 |
| wk_mind_4 | 没有新的任务要求时，我也会提前想象下一次工作可能遇到的麻烦。 | 无新任务时的预期负担 |

### 消息来了就想马上回应

性质：困扰或负担。看回应要求怎样影响原本的安排。

行动：选一类非紧急消息，和相关的人确认通常需要多久回复。

解释边界：值班、职业责任和经济处境会限制选择，不据此评价边界能力。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| wk_reply_1 | 休息时收到工作消息，我会放下正在做的事立即处理。 | 即时回应行为 |
| wk_reply_2 | 为了等一条工作回复，我推迟了原本的私人安排。 | 等待消息的时间代价 |
| wk_reply_3 | 有一条工作消息还没回复时，我很难安心做别的事情。 | 未回复时的不安 |
| wk_reply_4 | 对方没有说明期限时，我会默认这件事必须马上完成。 | 对期限的自动假设 |

### 基本需要被工作挤开

性质：困扰或负担。看吃饭、休息与生活安排是否被工作挤占。

行动：先找回一项容易被推迟的基本需要，必要时请人协助安排。

解释边界：现实资源不足、轮班与照护责任同样重要，不能简单要求减少工作。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| wk_needs_1 | 我把原本用于进餐的时间拿来补工作进度。 | 进餐被挤占 |
| wk_needs_2 | 已经明显疲惫时，我仍继续处理可以稍后再做的工作。 | 疲惫后的继续投入 |
| wk_needs_3 | 我因为工作占用了时间，取消了原本给自己安排的休息。 | 计划休息的取消 |
| wk_needs_4 | 处理完工作之后，我已没有精力照顾一件必要的生活小事。 | 生活照顾的余力 |

### 把工作量和取舍说清楚

性质：应对或支持。看哪些安排曾有商量的余地。

行动：需要接新任务时，试着说明已有安排，并确认优先顺序。

解释边界：没有协商条件不代表你不懂拒绝或不够勇敢。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| wk_negotiate_1 | 接到新任务时，我说明了手头已经承诺的工作。 | 工作量表达 |
| wk_negotiate_2 | 几项任务互相冲突时，我请相关的人一起确认先做哪项。 | 优先级协商 |
| wk_negotiate_3 | 发现原期限难以完成时，我提前讨论了可以调整的部分。 | 期限协商 |
| wk_negotiate_4 | 遇到超出自己能承担的工作量时，我提出了具体的协助请求。 | 协助请求 |

### 给工作安排一个收尾

性质：应对或支持。看有没有帮助自己从工作回到生活的小安排。

行动：下次收工时，只写一行待办，再做一个适合自己的收尾动作。

解释边界：这些做法不适用于所有工种，少做不代表纪律差。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| wk_transition_1 | 结束一天的工作前，我记下了下次接着做的第一步。 | 外置待办 |
| wk_transition_2 | 完成当天必要的工作后，我主动结束了工作页面或工具的使用。 | 结束工作的动作 |
| wk_transition_3 | 从工作转到休息时，我给自己留了一小段转换时间。 | 转换缓冲 |
| wk_transition_4 | 休息前，我区分了真正需要随时回应的事和可以等一等的事。 | 紧急性区分 |

### 下班后的生活有位置

性质：应对或支持。看工作以外的生活有没有得到一点空间。

行动：留住一项你实际觉得有帮助的安排，不必把休息变成新任务。

解释边界：有恢复活动也可能同时很累，不能抵消过重的工作负担。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| wk_restore_1 | 我为一件与工作无关、自己愿意做的小事留出了时间。 | 非工作活动 |
| wk_restore_2 | 工作很累的日子，我允许自己减少不必要的私人任务。 | 降低额外要求 |
| wk_restore_3 | 需要喘口气时，我找到了适合现实安排的一小段休息。 | 可行休息 |
| wk_restore_4 | 工作带来的压力难以独自处理时，我找人讨论了实际困难。 | 现实支持 |

行动：先减少一种非必要提醒，保留你需要的紧急联系。

解释边界：照护、工作和辅助工具可能需要频繁联网，不能只看次数。

性质：困扰或负担。看浏览目的是否逐渐变得模糊。

行动：下次打开页面前写下一个要找的内容，找到后允许自己离开。

解释边界：休闲浏览本身没有问题，关键是是否挤占了自己在意的安排。

## 决定与行动节奏 (DC)

观察期：过去两周。请按观察期内实际发生的情况回答。没有遇到相应情境，请选“不适用 / 不愿回答”，不用猜自己会怎样。题目不要求描述事件细节。

### 选择总想再比较一下

性质：困扰或负担。看寻找更好选项是否推迟了决定。

行动：先写下眼前选择必须满足的两项需要，再决定是否还需要更多信息。

解释边界：重要且不可逆的决定需要谨慎，这里不鼓励仓促行动。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| dc_compare_1 | 一个选项已经满足主要需要，我仍因为可能存在更好的而继续比较。 | 足够之后的比较 |
| dc_compare_2 | 没有新的重要信息时，我也会重新推翻刚作出的选择。 | 无新信息的反复 |
| dc_compare_3 | 面对相差不大的几个选项，我花的时间超过了自己原本的安排。 | 相近选项的时间成本 |
| dc_compare_4 | 向不同的人征求意见后，我反而更难决定下一步。 | 意见增多后的犹豫 |

### 想开始却找不到落脚点

性质：困扰或负担。看任务能否变成一个具体可做的动作。

行动：把一件事改写成一个看得见的动作，只尝试这一小步。

解释边界：开始困难可能与精力、资源、健康和任务设计有关，不等于懒惰。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| dc_start_1 | 准备开始一项任务时，我说不清最先要做的具体动作。 | 首步不清 |
| dc_start_2 | 想到任务的全部过程，我觉得眼前的一步也难以开始。 | 整体负担压住首步 |
| dc_start_3 | 我整理了许多准备材料，但迟迟没有进行任务本身。 | 准备替代开始 |
| dc_start_4 | 一项任务被打断后，我因为不知道从哪里接上而推迟继续。 | 中断后的重启 |

### 担心出错让动作变小

性质：困扰或负担。看错误与评价顾虑怎样影响行动。

行动：选一件低风险、容易修改的小事，允许先做一个不完整版本。

解释边界：高风险情境需要核查，不把合理审慎称为问题。

### 日常小事需要重新安排

性质：困扰或负担。看生活转换带来的实际任务负担。

行动：只挑一件影响基本生活的安排，寻找一个可行的临时做法。

解释边界：任务负担可能来自经济、住房、健康与照护需要，不应个人化。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| ch_tasks_1 | 过去很熟悉的一件日常小事，现在需要我重新学习怎么安排。 | 熟悉流程变化 |
| ch_tasks_2 | 处理变化带来的手续或安排，占用了原本用于休息的时间。 | 转换任务挤占休息 |
| ch_tasks_3 | 新的生活节奏让我难以按需要安排吃饭或休息。 | 生活节奏影响基本需要 |
| ch_tasks_4 | 几项安顿事项同时要处理时，我难以确定先做哪一件。 | 安顿任务排序 |

### 旧生活里有些东西舍不得

性质：困扰或负担。看变化中对熟悉生活的留恋和失落。

行动：允许自己保留一件有意义的小习惯，不急着证明已经适应。

解释边界：留恋和悲伤可能是正常反应，不按频率判定疾病。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| ch_loss_1 | 想到原来的日常安排时，我会明显感到失落。 | 熟悉日常的失落 |
| ch_loss_2 | 新的生活里，我会想念过去容易获得的一种陪伴。 | 关系支持的变化 |
| ch_loss_3 | 别人期待我赶快适应时，我觉得自己的感受没有位置。 | 适应期待与感受冲突 |
| ch_loss_4 | 想起生活改变前的状态时，我需要停下手头的事，给失落的感受留一点时间。 | 失落对当前活动的影响 |

### 给新生活留一点熟悉感

性质：应对或支持。看哪些熟悉的小事可以继续陪着自己。

行动：选一个现实中仍能保留的小习惯，让它成为这周的落脚点。

解释边界：旧习惯不一定都适合新环境，不要求勉强延续。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| ch_anchor_1 | 在新的安排中，我保留了一件自己愿意继续做的熟悉小事。 | 习惯续接 |
| ch_anchor_2 | 我找到了一个在新环境里可以暂时安心停留的位置。 | 空间落脚 |
| ch_anchor_3 | 一天的安排变化很多时，我仍留住了一项可预期的小安排。 | 可预期性 |
| ch_anchor_4 | 感到不适应时，我用一种熟悉而安全的方式让自己缓一缓。 | 熟悉应对 |

### 用小尝试认识新的节奏

性质：应对或支持。看探索能否按自己的步子进行。

行动：选一个低压力、方便调整的小尝试，做完再决定下一步。

解释边界：探索机会取决于现实条件，不以快慢衡量适应能力。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| ch_explore_1 | 面对不熟悉的安排时，我先尝试了其中一个较小的部分。 | 小范围探索 |
| ch_explore_2 | 发现原先设想不适合新环境时，我调整了安排。 | 依据环境修订 |
| ch_explore_3 | 我允许自己暂时使用一个不完美但能维持生活的办法。 | 临时方案 |
| ch_explore_4 | 完成一件安顿事项后，我给自己留了重新评估下一步的时间。 | 探索后的停顿 |

### 让安顿得到实际帮助

性质：应对或支持。看信息、陪伴与资源有没有接上。

行动：说清当前最缺的一项实际帮助，再寻找合适的人或服务。

解释边界：支持不可得时需要现实资源，不应要求只靠调整心态。

| 编号 | 原创题目 | 观察目的 |
|---|---|---|
| ch_connect_1 | 遇到不熟悉的流程时，我向了解情况的人询问了具体步骤。 | 流程信息 |
| ch_connect_2 | 我向可信任的人说过变化中最难处理的一部分。 | 困难表达 |
| ch_connect_3 | 新的安排让我忙不过来时，我接受过一项实际协助。 | 实际协助 |
| ch_connect_4 | 需要支持时，我查找了当前环境里能够联系的服务或资源。 | 新支持入口 |
