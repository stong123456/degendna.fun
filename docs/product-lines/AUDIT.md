## 自动检查

```sh
npm test
npm run audit:product
```

必须覆盖缺失、跳题、非法值、资源不能抵消困扰、少量回答不下结论、罕见资金提示、安全入口、精确同项复测、损坏存储、备份错密码与篡改、重复证据、旧版本拒绝、写入失败回滚、未知键隔离。

新增题库逐项核对：ID 唯一，观察期明确，题目只问可辨认的一件事，方向标识正确，适用人群与不适用选项明确，解释能追溯具体回答，行动与所问内容有关，来源/原创状态和版本明确。不把症状、人格、财富结果混为一谈。

## 浏览器验收路径

用独立本机测试环境与合成数据，不使用真实私密经历。桌面 1440×1000、手机 390×844，另测三种主题。

1. 首页 → 八个问题入口 → 正确题库；交易页必须包含四套新专题及完整交易自查。
2. 新专题答 12 题 → 保存草稿 → 刷新 → 继续草稿 → 回答一致。安全问题不应自动恢复。
3. 只答一题、全部跳过、资源题高频、生活影响明显等状态 → 结果有边界，无虚构健康等级。
4. 完成报告 → 保存 → 本地记录查看 → 同项复测；打开工具时不自动携带答案。
5. Reset 默认不保存 → 切主题文字仍在 → 主动勾选保存 → 周回看 → 逐条删除。
6. Play 未完成禁用结果 → 完成 → 查看规则和预览 → 下载 PNG；卡片无钱包、具体答案或健康结果。Play 不显示本地报告侧栏。
7. 隐私页加密导出 → 错密码/损坏文件拒绝 → 正常文件校验条数 → 取消保留原数据 → 确认替换 → 恢复后报告与工具可用。
8. 四类私密数据清除 → 重载确认不存在；主题保留。删除和恢复测试仅在经确认的可丢弃测试数据中执行。
9. 安全入口随时可达；选择“有过”先打开支持，无娱乐结果、无公开分享或危机分数。
10. 页面身份、非空、无框架错误、控制台无应用错误、无横向正文溢出、键盘焦点可见；保存桌面与手机截图。

## 内容与研究审计

- 用户理解访谈：未做前必须写“未完成”，不能用代码测试代替。
- 专业审阅：由独立合格人员完成，留日期、范围和修改记录。
- 信效度研究：独立研究设计和目标人群数据，未开展不能写“科学量表”。
- 商业化：先写清所售服务、数据处理、删除/导出和退款规则，再接支付；当前无交易能力。
- 标准量表：逐一核对授权、中文版本、计分、观察期和使用边界，不改写后沿用原名称。

## 失败处理

任何无法保存、不能删除、答案外传、错误危机分流、分享泄露健康记录都是发布阻断项。未验证项不能填成通过。保存失败保留文字，恢复前校验，不以错误状态覆盖现有数据。题库语义更改必须改版本且隔离历史比较。
