## 范围与证据

18 套原创自我观察模块、353 题、87 个内容维度；177 种近期命名结果（包括六套生活场景的单项和两项组合）；Play 四种风格及并列结果。安全支持为独立路径，不作为一种测评类型。

- `npm test`：120 项通过。新增测试覆盖每个模块的有效/非法/跳过回答、每个维度单一答案、资源与困扰并存、明确生活影响、支持建议一致性、损坏记录、导出完整性；177 种命名结果逐个验证可达及证据归属。
- Play 的 65,536 种完整答案组合全部验证：8 次计数、主方向、并列、原题依据均一致。不能把这一工程穷举称为心理测量效度验证。
- `npm run audit:product`：新增结果相关文件的答案外传检查，合计 19 项源码检查。
- `npm run build:xiaojing`：正式构建通过。三张主题背景使用站点绝对路径，构建器提示运行时解析；本机实际浏览器已确认三主题显示。
- 当前生产页通过 Browser Use 使用虚构答案抽查了快速自查和 Play，未保存或读取私人记录。连接器报告缺少清晰优势/盲点区、支持文案不够精确、手机悬浮条可能遮挡。其远端截图文件未取得可在本机检查的副本，因此本记录不将其作为已验收截图，不据此宣称完整视觉审计通过。
- Codex 内置浏览器两次页面读取超时；用户明确回复“允许”后，以独立自动化 Chrome 和新建浏览器上下文测试本地新版。只用虚构答案，不读取用户浏览器资料。

## 已发现并修正

| 问题 | 修正 | 验证 |
|---|---|---|
| 维度解释过于通用，具体行动没有在每个维度显示 | 显示原维度含义、实际原题依据、对应行动和边界；新增模块专属场景练习 | 18 模块 × 8 类答案分支；87 维度的行动和边界逐项保留 |
| 没有明确区分优势、资源和近期消耗 | 资源组达到覆盖，且至少两项、至少一半为高频时才概括已报告资源；困扰单独解释；未回答不反推缺点 | 资源单项、资源全高、负担全高、全部低频和跳过测试 |
| 快速自查遗漏支持与自主空间的类型候选 | 补“支持留白型 SA23”；展示规则独立版本更新 | 全 177 命名结果可达测试 |
| “比较难受、应付费力”未在所有支持说明里一致响应 | 计分结果和展示文案统一支持分支，并显示实际触发依据；已保存报告的依据从原情境重新整理 | 新报告与保存报告回看测试 |
| 持续或生活影响触发的通用文案可能让用户以为自己报告了“加重” | 改为中性说明，并列出真实选择，不断言所有可能原因都发生 | 选择大致不变的回归测试 |
| 汇总未充分强调还有未覆盖的困扰组 | 明列回答不足的组；不给无依据的完整人格结论 | 删除每个模块一组困扰回答测试 |
| 无组合提示的页面文案被写成看不出联系 | 说明只是未触发预设规则，不否认体验之间可能有联系 | 源码核对；新版界面已验收 |
| 网页和私密导出信息不完整一致 | 统一文字导出，保留状态、类型、优势/消耗、原题依据、练习、检查点、重要提示及求助边界 | 全模块分支的导出完整性测试 |
| 小镜读取页没有完整解释及单独重要提示 | 共享同一结果解读函数，显示资金/困倦等提示、优势、消耗、练习与证据 | 正式构建通过；真实浏览器主动读取已验收 |
| Play 仅有名称和一句短文 | 每个并列主方向显示倾向、可能优势、待核对盲点、具体练习和对应选择；短分享卡不增加私密内容 | 65,536 种组合；下载和布局已验收 |
| 手机悬浮提交条可能遮住题目 | 提交区改为正常文档流；结果区加滚动留白；优势/消耗手机单列 | CSS 已改，新版桌面/手机三主题已验收 |

## 新版结果的信息层次

1. 先呈现当前状态、支持优先级与可选行动；明显生活影响和安全关注优先，不被优势掩盖。
2. 展示本次观察期中的多个侧面：已有做法与支持、具体消耗；每条可展开查看原题依据。
3. 解释优势如何保留，困扰可从哪一步调整；没有足够资源答案时如实说不知道，不编造优点。
4. 每个模块都有独立的练习步骤、例子、易忽略问题、回看标准和反思问题。
5. 同时有资源和困扰时提出如何借力的反思问题，不推断因果或承诺有效。
6. 所有维度仍完整呈现，不用主类型代替完整回答；导出与主动读取共享解释。

## 解释边界和后续必做

这些问卷观察最近 7 天、两周或一个月的具体体验，不足以判定稳定人格，更不能由症状推断美德、缺陷或疾病。Play 仅呈现想象情境选择。用户希望了解稳定性格时，未来需要另行选择适合目标人群、授权清楚且独立验证的性格工具，不能把现有题库换个名字充当标准人格量表。

本轮未修改题目 ID、题意、选项、观察期或描述性频率计数。题库版本与历史同项比较不变；展示解读独立标记 `reflection-20261016-v2`、`types-20261016-v2`、`play-reflection-20261016-v2`。保存报告重新打开时使用当前展示规则整理原始证据，页面和导出明确标记展示版本。

一般建议的公开参考：WHO《Doing What Matters in Times of Stress》、NIMH《My Mental Health: Do I Need Help?》及原有支持资料。资料用于练习与求助边界，不代表机构认可本题库。
